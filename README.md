# DWTStardles

A daily Dancing with the Stars (US) guessing game. Guess the mystery celebrity; each guess compares 7 categories (season, known as, gender, age, pro partner, finish, premiere). Green = match, yellow = close, gray = no match.

Plain HTML/CSS/JS, no build step. Open `index.html`, or deploy on Cloudflare Pages (preset: None, no build command, output directory `/`).

Data in `data.js` was compiled from public Wikipedia season pages (seasons 1-34); ages and finishes are approximate.
